# Registro de uso de IA

## Asistencia utilizada

Se utilizó Codex (modelo GPT-6) como asistente durante la preparación de PC3, además de herramientas locales para consultar y modificar el repositorio. La automatización del navegador se usó para inspeccionar la aplicación local. GitHub se consultó para ubicar el repositorio del proyecto. La fuente de alcance académico fue la documentación y retroalimentación disponible en Mediación Virtual, no una fuente inventada por la IA.

## Trabajo asistido

- Revisión de los artefactos PC2, los comentarios del profesor y los lineamientos PC3.
- Propuesta de CU-01 y CU-02 como núcleo sin atribuir aprobación inexistente.
- Implementación de una API de demostración, migración de base de datos y UI para consulta de progreso y administración de vínculos.
- Revisión/actualización de trazabilidad, casos de uso, escenarios Gherkin, diagramas, decisiones, brechas y guías.
- Preparación de comprobaciones de compilación, API y documentación.

## Revisión humana pendiente

La IA puede haber interpretado de forma incompleta la rúbrica, los patrones de referencia o el contexto institucional. El grupo debe revisar el código y los documentos, corregir supuestos, confirmar los casos de uso con el profesor, verificar los resultados en su propio entorno y aportar sus propios commits de código. Este registro no atribuye revisión, aprobación ni trabajo a un integrante que no lo haya confirmado. La rama de preparación no se ha entregado en Mediación Virtual.
