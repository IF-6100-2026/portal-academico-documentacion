# RF-31 — Gestionar comunicación y avisos

| Campo | Detalle |
|---|---|
| Nivel | Requerimiento funcional general |
| Necesidad | Mantener informadas a las personas involucradas sobre el seguimiento académico. |
| Requisito | El Portal deberá facilitar avisos, acuses de consulta, mensajes y la atención de reportes por información no recibida. |
| Refinamientos conservados | RF-10 a RF-16 y RF-23. |
| Casos de uso | CU-03, CU-04, CU-05, CU-06, CU-08 y CU-12. |
| Estado | Generalización documental; correo, calendario y canales institucionales no se consideran implementados. |

## Criterios generales

- Los avisos se relacionan con una publicación y sus destinatarios autorizados.
- El Portal registra quién consultó un aviso y cuándo, según RS-02.
- Mensajes y respuestas se relacionan con el estudiante pertinente y respetan permisos.
- La queja por información no recibida puede presentarse y atenderse con historial.
- Los recordatorios respetan configuración vigente y no duplican envíos dentro de un intervalo.

## Trazabilidad

RF-10 a RF-16 y RF-23 → RF-31 → CU-03 / CU-04 / CU-05 / CU-06 / CU-08 / CU-12 → features existentes.
