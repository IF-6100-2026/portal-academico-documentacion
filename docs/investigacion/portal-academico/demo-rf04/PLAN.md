# Plan y alcance de la ejecución del agente

1. Inspeccionar el requisito RF-04 y las convenciones del proyecto.
2. Ejecutar las pruebas del backend sin cambios y guardar la línea base.
3. Escribir pruebas JUnit para los cuatro criterios, antes de añadir la implementación.
4. Ejecutar esas pruebas y registrar el fallo esperado por ausencia de las clases.
5. Implementar un objeto de datos, un error por campo y un validador puro.
6. Ejecutar la suite completa del backend y comprobar que se conservan las pruebas anteriores.
7. Preparar una demo de consola con datos sintéticos y ejecutar sus escenarios.
8. Revisar el diff y generar una propuesta de PR, evidencias y pasos de revisión humana.

## Participación real

El usuario autorizó que el agente preparara el trabajo mediante «Mae y puedes hacerlo vos???». Esa autorización permite avanzar en esta preparación técnica, pero no equivale a una revisión humana del plan detallado, del código o de las pruebas.

La selección de esta regla, los archivos nuevos, las pruebas y la ejecución técnica corresponden al agente. La revisión de los integrantes, los commits, la publicación del PR y su aprobación quedan pendientes. No se registrarán como acciones humanas ya realizadas.

La sesión actual no verifica el acceso ni la cuota de una cuenta gratuita. Si la rúbrica exige demostrar la modalidad gratuita, el equipo debe repetir o complementar la ejecución con esa cuenta y conservar la evidencia.
