# docs: investigación sobre agentes de generación de código

Se incorpora el trabajo del Tema 2 para el Portal Académico: investigación en Markdown, presentación con tres partes, demo Java y evidencia de su ejecución.

La demo implementa la validación de datos y fechas de RF-04. El agente registró 17 pruebas nuevas aprobadas y 22 pruebas aprobadas en total al incluir la suite existente del backend. Incluye seis escenarios de consola, bitácora, parche y declaración de uso de IA.
