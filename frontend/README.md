# Frontend del Portal Académico

Interfaz React 19, TypeScript estricto y Vite. Incluye ingreso por perfil, consulta de publicaciones del periodo (CU-01) y administración de vínculos por Dirección (CU-02). Todas las llamadas HTTP y sus tipos están centralizados en `src/api/academic.ts`.

Seguir la [guía de ambiente](../docs/06-configuracion/ambiente-de-desarrollo.md). Los datos disponibles son ficticios y se cargan por Liquibase.
